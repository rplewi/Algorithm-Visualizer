# Good notes for these algorithms

## *Indices
- The specific indices that are being selected will be highlighted with the specific hashset.   
    - Colors are not determined by name and can be changed if needed.

## For loops
- Can use i and j incrementors for flagging state.
- Allows us to see the specific thing it is viewing and dont have to worry about conditions that need to be met.

## While loops
- Need to have boolean variable checks in order to handle specific while loop conditions.
- These are specifically noted in the insertionSort algorithm I had to implement.
    - variables like "hasKey", and "isScanning" are used to check our specific while loop conditions.
    - We are able to see what specifically we need, and in this case it was a key and if we were scanning.
    - If we weren't doing either, we re-check our variables in the initial if statement and reassign these values.
    - This allows us to bypass the need for while loop checks, and lets us see the specific step we would be on.
